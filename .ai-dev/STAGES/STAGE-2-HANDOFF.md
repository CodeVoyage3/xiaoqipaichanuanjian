## 六、不可违反的高风险业务规则

### 1. 局部增量

Excel 只描述本次实际出现的数据。未出现不等于不存在。本次缺少整个历史商品，或出现商品但缺少其某个历史批次，两种情况都不得触碰缺失记录。

### 2. 商品唯一主体

- 唯一身份只认 `商品编码`。
- 同编码名称/条码变化仍是同商品，只更新当前值；历史快照保留。
- 编码变化视为新商品，不自动合并；编码为空进入异常。

### 3. 批次唯一键

- 有生产日期：`商品编码 + 生产日期 + 有效日期`。
- 无生产日期：`商品编码 + 有效日期`。
- 历史出现过的组合永久是旧批次，停止跟踪后再次出现也不是新批次。

### 4. 表头、食品与冲突

- 所有表头先 Trim 等规范化；规范化后同名列按文件级异常拒绝。
- 食品字段是 `商品大类`，值为 `食品`；非食品跳过，不作为错误，不影响已有食品。
- 同商品库存总数出现多个值时，本次不更新该商品库存、不触发归零，并报告全部冲突值；不能因此丢掉其他可独立处理的正常批次。

### 5. 商品库存归零

只有本次 Excel 明确包含该商品、库存字段明确为 0 且该商品没有库存冲突时，才能触发。它结束商品全部历史和当前批次、关闭开放任务、使草稿失效；历史仍保留。其优先级高于新批次、累计到货增加和阶段触发。商品未出现时严禁推断库存为 0。

### 6. 排查 0 件

正式排查某批次为 0，只停止该批次后续跟踪，不等于商品库存归零；其他批次不受此规则直接影响。

### 7. 累计到货与恢复

- 真正新到货只认 `当前累计到货 > 历史最高累计到货`；下降、回升到旧最高值不算。
- 仅因批次排查 0 件停止，且商品从未归零、当前商品库存大于 0、累计到货首次突破历史最高值时，该旧批次才可恢复，并直接计算当前最高阶段。
- 商品曾发生商品级库存归零后，历史旧批次永久不得恢复；库存恢复只允许数据库从未出现过的真正新批次进入当前代。

上述库存归零、排查 0 件、恢复和阶段计算主要属于 Stage 3；Stage 2 只能在批准范围内正确采集和规划输入，不得提前编写完整状态机。
