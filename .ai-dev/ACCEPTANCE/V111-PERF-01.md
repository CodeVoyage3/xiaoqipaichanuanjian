## C. 当前宿主机内存与 CPU

- 使用当前物理宿主机真实 Intel GPU/driver，不以 Windows Sandbox 替代最终内存验收。
- 记录 Private Working Set、Private Bytes、VMMap Private Data、native Heap、WriteCombine、CPU。
- 64 MiB WriteCombine 块不再出现；WriteCombine 不得恢复为数百 MiB；Private WS 相比 893.8 MiB 出现数量级下降。
- 同等空闲状态 Private WS >250 MiB：`PAUSE / NOT_ACCEPTED`。
- 记录空闲、页面切换、长列表滚动 CPU；不得持续高 CPU、明显卡顿或持续打满单核。

用户本人连续操作建议 15～30 分钟，覆盖：首页、待排查任务、今日排查、排查详情、商品明细、商品详情、排查历史、数据导入、备份恢复、设置、提醒弹窗、托盘最小化/恢复、最大化/恢复、长列表滚动，以及 Windows 125%/150% 缩放。

重点观察滚动/切页流畅性、字体清晰度、表格闪烁、弹窗与托盘恢复。最终回执仅接受 `GUI PASS` 或 `GUI FAIL`。
