# S9-T06 在线更新故障诊断（不升级）

在出现失败的标准 Win11 实机上：

1. 解压整个诊断包到一个普通文件夹；保留正式 v1.0.0 安装，按平时方式从托盘退出应用。
2. 双击 `Run-Network-Diagnostic.cmd`，不用管理员，不改代理/网络设置。等窗口显示完成（通常几十秒，遇到超时最长约12分钟）。
3. 将同目录新生成的 `network-diagnostic-….jsonl` 发回当前话题，并说明是在标准实机还是Sandbox执行、是否与失败时使用相同网络。只需标准实机这一份；不要做After。

此工具复制已安装的正式1.0.0程序/runtime到TEMP/GUID，用原始下载器实际检查、下载并验签1.0.1。即使成功也不安装、不启动Updater、不启动主程序，不读取数据库/备份，不修改已安装文件、系统安全或代理设置，不要求安装.NET。

日志包含阶段、host、路径类别、HTTP状态、redirect hop、冻结重定向规则检查结果、异常类型/错误码、DNS/TLS/连接/超时分类、runtime版本、代理环境变量是否存在。不会保存URL query、代理地址/凭据、原始异常消息、业务数据。原始异常文本全部移除，以分类/native error code替代；请只回传JSONL，不打包TEMP缓存、程序或ZIP。

这是验收侧诊断工具，不是修复版，也不是1.0.2。成功只能说明该次诊断网络可用，不能代替应用内“立即更新”GUI验收。原有Init/Before和失败截图请继续保留。
