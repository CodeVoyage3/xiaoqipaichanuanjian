## 二、业务与查询事实

- Dashboard 只统计开放 Task；同商品按唯一开放 Task 的 HighestStage 计数一次，并返回固定最多 20 条紧急任务。
- SearchOpenTasks 支持名称、编码、条码、四阶段筛选、默认 50 条分页和稳定跨页排序；非法阶段、页码和页大小在查询前拒绝。
- Dashboard/Search 的排序只调用 `ExpiryStageCalculator.GetStagePriority`，没有字符串排序或第二套 switch/CASE 优先级。
- GetDetail 明确区分 `open / not_found / completed / system_closed`，没有把已完成或系统关闭伪装成不存在。
- 开放详情返回 Product、每个 TaskItem 自身 Stage、Batch 当前到货量、AttentionVersion、RequiresReconfirmation 和有效 Draft CheckedQty；生产日期 null 原样保留。
- 正常批次只取同商品 `active` 且未进入当前开放 TaskItem 的 Batch。
- 每个相关 Batch 的最新正式结果按 `SubmittedAtUtc DESC → InspectionId DESC → InspectionItemId DESC` 稳定选择。
- 无效 Draft 不作为可恢复草稿；查询不创建、补齐、更新时间、失效或删除任何 Draft/DraftItem。
- 查询异常原样传播；正常空结果、Task 不存在和数据库执行失败可区分。
