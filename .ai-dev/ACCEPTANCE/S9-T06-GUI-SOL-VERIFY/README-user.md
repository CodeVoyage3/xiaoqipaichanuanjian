# S9-T06 真实 GUI 诊断候选

这是未发布的 v1.0.2 诊断候选，不是正式修复安装包。它使用完整 WPF App，在全新 TEMP/GUID 合成数据目录运行；弹窗明确模拟 source v1.0.0，向真实 GitHub 准备 v1.0.1，只下载验证，不执行 Updater、不安装。正式 v1.0.0/v1.0.1 资产保持原样。

1. 在原失败的标准 Win11 实机解压整个 ZIP，双击 `Start-GuiDiagnostic.cmd`。不需要管理员权限，不放进原安装目录。
2. 等待“发现新版本”，确认诊断横幅显示“实际版本 v1.0.2、模拟 source v1.0.0、只准备，不安装”，点击一次“立即更新”。
3. 等待成功或失败，记下提示。然后从托盘菜单“退出应用”，把启动窗口显示位置的 `s9-t06-network-diagnostic.jsonl` 回传，并说明是否关闭过提示窗口、主窗口或点过取消。

不用重复运行独立网络探针，不用导入门店数据，也不用做 After。若 Windows/SmartScreen 拦截，记录提示，不关闭系统安全功能。候选成功仍不能替代原安装版升级成功；它只用于定位 GUI 失败阶段。
