## V1.1.0_MANUAL_INSTALL_CROSS_SCHEMA_RISK

- v1.0.9 databases have migration9; v1.1.0 databases have migration10.
- `StoreExpiryInspector-Setup-1.1.0.exe` treats an existing migration9 database as `OlderSchema` and safely blocks installation. It allows no database or an exact healthy ordered migration10 database only.
- Therefore an existing v1.0.9 store cannot complete this cross-Schema upgrade by downloading and directly running the ordinary v1.1.0 Setup from `[点击网盘下载]`.
- This is an explicit release-channel limitation. Migration9 was not added to Installer ALLOW, and no offline upgrade protocol was designed in this preflight. Product decision is required before publication.
