## 解析行为验收

- 使用 Open XML SDK 3.5.1 只读打开 `.xlsx` 首个工作表，文件句柄在读取后释放。
- 文件 SHA-256 由标准库计算并输出 64 位小写十六进制。
- 表头只做 Trim；空表头、Trim 后重名和必要列缺失均整份抛出 `InvalidDataException`，缺失列一次完整报告。
- 11 个批准字段以原始文本或 `null` 输出，行 DTO 保存 Excel 行号；不在本卡转换业务日期或数量。
- 数据行按真实单元格引用定位，稀疏单元格不会串列；完全空白行忽略。
- 共享字符串、内联字符串、普通字符串、布尔和数值单元格均可读取。
- 数值标识不经过 `double`；15 位整数保持完整，整数科学计数原始值按十进制字符串展开；文本前导零逐字符保留。
