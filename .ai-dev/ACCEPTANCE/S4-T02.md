## 二、业务与事务事实

- SaveDraft 对开放 Task 的唯一有效 Draft 原地 patch；Item 未包含时保留，明确包含时严格区分 null、0 和正数，新 Item 即使为 null 也保存其观察 AttentionVersion。
- 检查人空白规范化为 null，非空 Trim；检查日期只接受空值或不晚于显式 BusinessDate。
- 普通保存不修改 TaskItem 的 AttentionVersion、Stage、RequiresReconfirmation 或时间戳，也不推进既有 DraftItem.ConfirmedAttentionVersion。
- 陈旧页面可保存旧观察版本下的用户输入，但不能清除新版本重新确认；未来版本和数据库 TaskItem/Batch 版本不一致均拒绝且不修复。
- ReconfirmItem 只在开放 Task、当前 Item/Batch、有效 DraftItem、非空 CheckedQty、当前版本完全匹配且 RequiresReconfirmation=true 时原子确认；精确当前版本重放为无变化。
- ClearDraft 只删除开放 Task 的有效 Draft，先删 DraftItem 再删 Draft；无 Draft 幂等，系统失效 Draft 和已关闭 Task 均拒绝。
- 三个动作均拒绝带 pending changes 的 DbContext，进入事务后清理旧跟踪并重新读取当前事实；自有事务失败会回滚并清空 tracker，外层事务所有权不被抢占。
