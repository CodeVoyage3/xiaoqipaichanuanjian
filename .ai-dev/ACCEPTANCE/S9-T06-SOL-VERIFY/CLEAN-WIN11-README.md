# S9-T06：独立 Windows 11 人工验收

仅在你指定的另一台 Windows 11 x64 电脑执行。只使用本包合成 Excel，不导入门店文件。若已有本软件数据/安装目录，采集器会停止；不要删除或重置。Win10 不在本次验收范围。

1. 从 https://github.com/CodeVoyage3/xiaoqipaichanuanjian/releases/tag/v1.0.0 下载正式 `StoreExpiryInspector-Setup-1.0.0.exe`，放在本文件同目录。双击 `Collect-CleanWin11.cmd`，选择 **1（Init）**。记录 `winver` 截图，确认这台电脑没有预装现代 .NET Runtime；脚本同时记录环境信息。若预装过，照实反馈，不称为无 .NET 干净机证据。
2. 直接运行 Setup，不使用“以管理员身份运行”。记录是否要求提权、SmartScreen/未知发布者实际提示；不要关闭系统安全功能。验证桌面、开始菜单快捷方式，启动显示 **v1.0.0**，关闭重开一次；启用自启动后注销/登录验证。出现 v1.0.1 提示时先选“稍后提醒”。
3. 导入 `S9T06-合成测试.xlsx`（3 个商品）。提交“合成饼干”的下架排查，数量 **2**，排查人 **S9T06**；其他待办不提交。提醒时间改为 **23:59**，手动建立一次数据库备份。拍一张版本/数据基线截图。托盘右键选择“退出应用”，然后采集器选 **2（Before）**。尽量同一天完成后续步骤，之后不再导入、修改业务或新建备份。
4. 启动 v1.0.0，让软件实际检查 GitHub；记录“当前 v1.0.0 / 最新 v1.0.1”，点击“立即更新”。记录下载、退出、重启及 **v1.0.1** 显示，建议一段短录像。不复制 ZIP 到缓存，不另运行 1.0.1 Setup 替代升级。
5. 查看 Dashboard、待办、今日排查、历史、提醒、设置及备份，确认原测试内容仍在。托盘“退出应用”，采集器选 **3（After）**。
6. 正常卸载，保留数据；采集器选 **4（Uninstalled）**。把最终 `evidence-…-Uninstalled.zip`、上述截图/录像和下方回执发回当前话题。Sol 再独立核对版本、程序树、数据库全部字段/BLOB、备份、ACK、migration、完整性和外键。不把这些文件上传 GitHub Release。
