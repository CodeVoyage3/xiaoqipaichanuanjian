## 唯一实施范围

本轮只做 WPF UI 与 ViewModel 必要的筛选编排调整，并以现有待排查任务查询结果、canonical Stage、导航命令和局部/共享 WPF Style 为权威来源。

### A. 左上角品牌区域

- 删除“门店效期排查软件”品牌文字，保留现有产品/盾牌图标。
- 把侧边栏折叠箭头从最左侧移动到顶部区域右侧，即原品牌文字区域右侧。
- 保持折叠命令、折叠后导航行为、Tooltip、Automation 名称及展开/收起语义不变。
- 删除文字后自然收口，不留下明显大块空白；不为此重构整个侧边栏或动态窗口结构。

### B. 左侧导航顺序

展示顺序固定为：

1. 首页
2. 待排查任务
3. 今日排查
4. 排查历史
5. 数据导入
6. 数据备份与恢复
7. 设置

只调整 XAML 展示顺序，不改变页面命令、ShellPage、ViewModel 权威或数据加载语义。

### C. 阶段下拉筛选

- 删除待排查任务页横向阶段按钮组，改为标准 ComboBox：`阶段 [全部阶段 ▼]`。
- 下拉项及顺序：全部阶段、过期、收仓、2折、5折；默认全部阶段。
- 复用现有 `StageFilterOption` 与 canonical Stage 值，不修改 Stage 计算、算法或 ProductTask 生成逻辑。

### D. 大类下拉筛选

- 在阶段下拉附近增加 ComboBox：`大类 [全部大类 ▼]`；默认全部大类。
- 选项来自当前真实待排查任务数据的 `CategoryName`，去重后展示；空值按现有数据事实安全处理，不在 UI 硬编码大类业务规则。
- 搜索词、阶段、大类始终取交集；至少支持“搜索词 + 5折 + 某一大类”。
- 分页、筛选后商品总数和空状态必须基于三类条件的最终交集。

### E. 清空筛选

- 一次恢复搜索词为空、阶段为全部阶段、大类为全部大类、分页为第一页。
- 右侧“共 X 个商品”反映筛选后数量；上一页/下一页继续基于筛选后结果工作。

### F. 有限范围蓝色视觉降噪

- 黑/灰/白为默认主体；明显蓝色只保留给当前导航选中、真正 Primary、输入/下拉 Focus 及少量必要状态强调。
- 普通输入框、普通下拉框、刷新、清空筛选、上一页、下一页、次级按钮及普通容器默认使用浅灰边框、白色或极浅灰背景和深灰文字。
- Hover 与 Pressed 使用中性灰阶；Focus 可使用蓝色 border/ring；Disabled 使用低对比度灰阶。
- 优先调整现有 `MainWindow.xaml` 范围内可复用 Style，避免逐控件重复属性；不得重写全局 Theme，不得大面积修改 `App.xaml`。
- `StageBadgeTemplate` 及其既有业务状态颜色契约完全冻结。
