## 产品合同

1. GitHub 已成功确认新版本 `X` 后，用户点击“立即更新”，继续走现有 `CheckedRelease`、包准备、下载、验签、校验和安装链。
2. 只有包准备/下载返回 `UpdatePackageOutcome.NetworkUnavailable` 或 `UpdatePackageOutcome.RateLimited`，才调用现有 `GiteeManualUpdateChecker.CheckAsync`。
3. 只有 Gitee `Outcome=UpdateAvailable`、`LatestVersion` 非空且严格等于 GitHub `X`、`ManualDownloadUrl` 非空，并且 `result.LatestVersion == result.Release.Version == X`，才进入国内兜底 UI。
4. Gitee 只提供 `ManualDownloadUrl`；不得覆盖 GitHub 的版本、`CheckedRelease`、更新说明或发行身份。
5. 国内链接继续由现有 checker 限制为 absolute HTTPS、默认端口、无 user-info、`IdnHost=pan.quark.cn`；只用 Windows 默认浏览器打开，不自动下载、执行或送入自动更新链。

## Outcome 边界

- 唯一白名单：`NetworkUnavailable`、`RateLimited`。
- 明确 `SAFE_BLOCK / NO_DOMESTIC_FALLBACK`：`Cancelled`、`ManifestMissing`、`SignatureMissing`、`InvalidManifest`、`InvalidManifestSignature`、`SigningNotConfigured`、`UnsupportedProtocol`、`UnsupportedPlatform`、`VersionMismatch`、`PackageVersionMismatch`、`SourceNotSupported`、`AssetMissing`、`AssetTooLarge`、`SizeMismatch`、`HashMismatch`、`UnsafeArchive`、`IoFailure`。
- Gitee 较旧、较新、同当前版本、失败、超时、HTTP error、metadata/URL 无效或 URL 缺失时，维持普通在线更新失败，不展示网盘入口。
