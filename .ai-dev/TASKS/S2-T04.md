## 预览文件身份契约

定义普通只读 `ImportPreviewIdentity`（名称可等价），至少包含：

- 规范化绝对文件路径。
- 预览时源文件名。
- 预览时 64 位小写 SHA-256。
- 对应的 `ImportPlan`。

创建身份时：

- 文件路径不得为 null、空白或不存在相对含义；使用 `Path.GetFullPath` 固化当时路径。
- 预览 SHA 必须精确为 64 位小写十六进制；不得接受大写、空白包裹或非法字符后静默规范化。
- 文件名必须与路径的 `Path.GetFileName` 及 `ExcelWorkbookDto.SourceFileName` 精确一致，避免把一个文件的解析结果绑定到另一文件路径。
- `ImportPlan` 和 `ExcelWorkbookDto` 只作为普通只读输入；不复制或修改计划。

不依赖文件修改时间、长度或 OS file ID 作为最终身份；内容 SHA-256 才是准入依据。用相同字节替换文件视为同一内容，可通过。

## 确认前重读与 TOCTOU 边界

- 确认时重新打开预览身份中保存的同一绝对路径，读取全部源文件字节并重新计算 64 位小写 SHA-256。
- 文件读取使用只读方式；读取期间不允许其他进程写入或删除该文件，避免边读边改得到不稳定内容。
- 哈希不一致时返回明确拒绝结果 `file_changed`，不得生成可确认契约，并提示重新解析/预览。
- 文件不存在返回 `file_missing`；目录不存在、拒绝访问、被独占、I/O 失败等返回 `file_unavailable`。对外结果不得泄露完整堆栈或敏感系统信息。
- 成功时，确认契约持有本次重读并验证过的不可变工作簿字节视图、已验证哈希、文件名和 `ImportPlan`，供后续卡消费同一份已验证内容，避免哈希通过后再次从路径读取另一份文件。
- 不向调用方暴露可变 `byte[]`；使用内部副本和 `ReadOnlyMemory<byte>` 或等价只读形式。后续写入仍不属于本卡。
- 确认完成后即使路径文件再次变化，已生成契约中的字节和哈希仍必须保持一致。

## 确认资格与无变化规则

- `ImportPlan.HasChanges == false` 时返回 `no_changes`，不得读取为正式导入准备的契约，不得产生 Import 记录或“成功导入”语义。
- `HasChanges == true` 且文件身份一致时才返回 `ready` 和非空确认契约。
- 失败、取消、预览、解析、文件变化和无变化都只是内存流程结果，不是 `imports.status`，不得映射为正式 Import 状态。
- 结果至少提供稳定代码、是否允许确认和安全用户提示；不要用异常承载预期的文件缺失/变化/无变化分支。
- 参数为空、身份 DTO 构造非法属于编程错误，可使用标准参数异常。

## imports.status 口径

- 定义最小明确的 Stage 2 状态值：`Succeeded`、`Undone`。
- 提供最小验证方法或值类型，证明除此之外 `Preview`、`Parsed`、`Failed`、`Cancelled`、`NoChanges`、空值及大小写变体均不合法。
- 本卡成功确认契约只声明未来成功提交后的目标状态为 `Succeeded`；不得提前创建正式记录。
- `Undone` 仅供 S2-T08 后续撤销后的正式记录状态使用，本卡不执行撤销。
- 不增加数据库 check constraint，不修改 `ImportRecord.Status` 类型，不为两个值建设通用状态机。

## new_task_product_count 口径

- Stage 2 确认契约可携带一个名称明确的 schema 占位值，固定为 `0`，供后续持久化卡填写当前非空字段。
- 该值不得加入 `ImportPreview`、`ImportPlan` 或任何用户可见计数，不命名或解释为“新增 0 个任务”。
- 不计算任务数量，不查询 Tasks，不调用任务引擎，不生成任务计划。

## 必须测试

- 使用 S2-T01 实际 `ExcelTemplateReader` 产生的文件名和 SHA 创建预览身份；确认同一未变文件得到 `ready`，重新计算哈希与预览哈希一致。
- 成功契约中的工作簿字节重新计算 SHA 与契约哈希一致；确认成功后修改路径文件，契约字节与哈希仍不变。
- 预览后修改文件内容、以不同内容替换同名文件、传入预览 SHA 与当前文件不一致，均返回 `file_changed`、无确认契约并要求重新预览。
- 预览后删除文件返回 `file_missing`；目录删除、拒绝访问或以 `FileShare.None` 独占文件时返回 `file_unavailable`。平台无法稳定构造的权限场景至少覆盖独占 I/O。
- 用完全相同字节替换同名文件仍可通过，证明身份依据是内容哈希而非时间戳。
- `HasChanges == false` 返回 `no_changes`，无确认契约；SQLite `imports` 数量保持 0，且无需访问 DbContext 的实现代码。
- 非法路径、文件名不匹配、非法/大写 SHA 拒绝构造身份。
- 状态合法集合精确为 `Succeeded`、`Undone`；解析、预览、失败、取消、无变化及大小写变体全部拒绝。
- ready 契约的目标状态只能是 `Succeeded`；schema 任务计数占位固定为 0，但反射证明 `ImportPreview` / `ImportPlan` 不暴露 NewTask 或任务数量属性。
- 源码搜索证明没有 DbContext、SaveChanges、ImportRecord 实例化、Product/Batch 写入、事务、快照、BLOB、裁剪、撤销、任务或 UI。
