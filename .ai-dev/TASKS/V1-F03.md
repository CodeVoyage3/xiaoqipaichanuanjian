## 产品闭环

`导出今日待排查任务（可部分选择） → 门店打印或 Excel 填写 → 独立回导 → 零写入待确认 → 填写排查人/日期 → 写入既有 Draft → 复用既有正式提交`。

Excel 回导不是商品源数据导入，不修改 Product/Batch 源身份；未确认前不创建 Inspection、InspectionItem、Revision，不推进 HandledAttentionVersion，不完成 Task，不停止 Batch。

## 冻结语义

- 一批次一行；同商品多批次展开。
- 排查数量空白 = 未完成，`0` = 正式无库存，正整数 = 现场仍有库存；不得互相转换。
- 稳定匹配使用现有系统主键和版本事实，不只依赖商品名、条码或行号。
- 回导时数据库是唯一当前事实；陈旧、身份被改、任务集合变化、库存/到货变化或已处理项不得静默覆盖。
- 用户确认后只写既有 Draft；最终提交必须调用现有 `InspectionSubmissionUseCase`，不得复制正式落库逻辑。
- Excluded、Unresolved、无合法 Managed lifecycle 商品不进入计划，也不能由回导重新进入生命周期。
- V1-F02 Reminder 规则保持不变。
