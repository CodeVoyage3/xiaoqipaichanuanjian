## 产品不变量

1. 只有完整可信检查确认存在更高 stable 正式版本后，才先持久化 `FORCED_UPDATE_REQUIRED`，再显示 GUI；内存状态或先弹窗后落盘均不合格。
2. 强制状态下业务始终关闭，只允许“立即更新”或“退出软件”；无稍后、忽略、跳过、取消后继续、断网继续、重启继续或托盘绕过。只有合法升级完成并可信确认当前版本已满足当次 required/latest，才解除强制状态。
3. “24小时”只宽限临时网络失败：无强制/安全阻断且最近可信成功检查不超过 24 小时才可继续；失败不得刷新成功时间。超过 24 小时仍不能可信检查时只允许重试/退出。
4. 全新环境可有一次最多 24 小时首次联网宽限。普通重启不重置；损坏、矛盾、未知 schema 或单个状态文件缺失不产生新宽限。明显 UTC 回拨必须联网重验，不能增加剩余宽限。
5. 网络暂时不可用与安全验证失败严格分流。manifest 缺失/格式或身份错误、RSA 签名/公钥身份错误、ZIP hash/size、protocol、release/tag/version、source/target migration、archive 安全等失败均 fail-closed；持久安全阻断不能被下一次普通网络失败解除。
6. 当前不能直达 latest 时，只沿所有节点均经 stable Release、production RSA-PSS/SHA256 manifest、source version/migration、target migration、protocol 与 package identity 校验的合法路径升级。无路径时明确提示官方升级方式，禁止硬装 latest 或自动 Setup fallback。
7. 用户第一次点击“立即更新”后持久化 `AutoContinue=true`。每次只下载和执行下一跳；一跳完成、恢复/ACK 完成并重启后自动重新确认和继续，最终可信到达 required/latest 前不开放业务。
8. 启动检查之外，每 6 小时重新检查一次；不得用长期不关闭应用规避升级。周期可仅在 Sol 有现有 API rate-limit/架构证据时调整并记录理由。
