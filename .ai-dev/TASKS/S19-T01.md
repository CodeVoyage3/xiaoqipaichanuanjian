### C｜当前事实逐行解析

- 先以唯一 ProductCode 定位 Product，再以批准的日期键唯一定位 Batch，再定位该 batch 当前唯一 open task item。
- 非空行逐项重验 managed/baseline、商品库存、batch active/nonzero、当前 stage/attention/handled、task open、未完成/未提交、无需重新确认等正式合同。
- 空白行不需要形成 Draft；非法整数、负数、小数、重复业务身份、无法匹配或状态变化只产生该行问题。
- Preview 是说明性快照；Apply/Submit 必须再次校验当前事实，竞态行跳过，其他有效行继续。

### D｜真正部分提交

- 仅本次有效且非空行进入 Draft/Submission；同 ProductTask 可提交子集。
- 权威提交逻辑支持指定 task item 子集；默认未指定时保持原单任务全量行为。
- 同一事务内：创建只覆盖提交子集的 Inspection；只对提交子集执行 0 数量 lifecycle 与 HandledAttentionVersion；完成原 task；清除旧有效 Draft；为未提交且仍有效的剩余 items 建立同商品唯一 successor open task，HighestStage 由剩余 items 重算。
- 最终 completed task items 与 InspectionItems 覆盖一致；successor items 与未提交当前有效集合一致；两集合无重叠、无丢失。后续 `ProductTaskAggregator` 继续汇入唯一 successor open task。
- 行级无有效结果时不创建空 Inspection、不完成任务、不写 0。

### E｜UI 与错误

- 大表读取超过短暂阈值显示“正在读取排查结果，请稍候”“数据较多时可能需要一些时间，请勿关闭软件”等不确定进度；所有出口关闭 loading。
- 文件占用、损坏、工作表/A:L 结构错误分别显示任务要求的大白话与下一步；日志保留完整异常。
