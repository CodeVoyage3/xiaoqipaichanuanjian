## 四、首次安装可选择程序路径

首次安装必须显示目录选择页，默认仍为：

`%LOCALAPPDATA%\Programs\StoreExpiryInspector`

用户可选择本地普通可写路径，例如：

`D:\门店效期排查软件`

必须支持包含中文和空格的路径。

安装根安全规则：

- 必须是本地文件系统的普通目录；
- 当前用户可写；
- 不允许 UNC/网络路径；
- 不允许 reparse point / junction / symlink；
- 不允许 traversal、ADS、相对路径、根路径异常；
- 不允许需要管理员权限的受保护目录；
- 不允许与固定数据根 `%LOCALAPPDATA%\StoreExpiryInspector` 重叠或互为祖先/子目录；
- 不因选择目录改变 `PrivilegesRequired=lowest`。

不要单纯关闭旧 `WizardDirValue == fixed root` 断言；要把它重构为“chosen install root 的规范化与安全验证”。

## 五、已安装用户不得在升级时搬目录

已有同 AppId 安装时：

- 读取并使用原实际安装目录作为唯一升级根；
- 升级/修复不显示或不允许改变到其他目录；
- `UsePreviousAppDir` 或等价机制必须真实生效；
- 若安装身份记录与实际程序树不一致，fail-closed，不猜目录；
- 不实现升级时程序目录迁移。

用户若未来需要搬家：卸载程序但保留数据，再重新选择新目录安装。本卡不做自动搬家。

## 六、固定数据根保持不变

卸载仍保留用户数据的既有产品规则不得改变。
