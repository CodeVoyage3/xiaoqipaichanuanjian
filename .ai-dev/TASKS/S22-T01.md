## 唯一目标

在现有 WPF Shell 中增加独立“商品明细”入口：列表一行一个 Product，进入商品级详情后查看该商品全部批次；不改变现有业务、Schema、版本或发布链。

## 商品明细页

- 数据管理导航固定顺序：商品明细、数据导入、数据备份与恢复；其他导航语义不变。
- 标题“商品明细”；副标题“查看系统当前所有商品的汇总信息，点击详情查看批次”。
- 搜索：商品名称 / 商品条码 / 商品编码。
- 筛选仅：大类、阶段、任务状态；不做库存筛选。
- 一行一个 Product；优先复用现有查询、50 条分页、筛选、清空、刷新、空态和错误态模式。
- 列：商品名称、商品条码、商品编码、大类、批次数、当前总库存、最近到期日、最高风险阶段、待处理任务、操作；列表不显示“最近导入”。
- 操作仅“详情 →”。

## 商品级聚合合同

- 批次数：该 Product 当前持久化的全部 Batch 数量。
- 当前总库存：`Product.EffectiveStockQty`，不得求和 `Batch.CurrentArrivalQty`。
- 最近到期日：该 Product 中 `TrackingStatus == "active"` 的 Batch 最小 `ExpiryDate`；无结果显示 `—`。
- 最高风险阶段：活跃 Batch 的 `CurrentStage` 按现有 `ExpiryStageCalculator` 优先级取最高；无可跟踪风险显示“正常”。
- 待处理任务：该 Product 唯一 open ProductTask 下当前 `ProductTaskItem` 数量；没有 open task 为 0。
- 最近导入：`Product.LastSeenImportId` 对应成功、未撤销 Import 的 `ConfirmedAtUtc`；无值显示 `—`。

## 商品详情页

- 面包屑：商品明细 / 商品详情。
- 标题“商品详情”；副标题“先看商品整体情况，再查看各批次明细”。
- 右上：返回列表；存在当前 open task 时显示/启用“去排查”，并复用 `ShellViewModel.OpenDetail(taskId)`；无 open task 不制造入口。
- 顶部身份区只显示商品名称、商品编码、商品条码、大类、最近导入。
- 有待处理批次时显示“该商品存在需关注批次，请优先查看下方批次明细。”
- KPI 只显示一次：批次数、当前总库存、最近到期日、最高风险阶段、待处理任务。
- 不创建独立商品概览卡；最近排查日期仅作轻量辅助信息；不展示保质期、总效期或重复的待处理判断。

## 批次明细

- 批次以生产日期 + 到期日期识别；不显示或生成业务批次号/批次伪字段。
- 字段：生产日期、到期日期、累计到货（空间不足可删除）、当前阶段、任务状态、操作。
- 不得出现“当前库存”字段。
- 排序：Stage 风险优先，再按最近到期日，最后用稳定主键顺序。
- 当前正式阶段仅：正常、5折、2折、收仓、过期；复用 `ExpiryStageCalculator`。
- Batch 属于当前 open task 的 TaskItem 时显示“去排查 →”，复用该 task 的现有排查详情；无待办批次操作显示 `—`。

## 最近导入信息

- 最近导入日期只在顶部商品身份区展示；不保留底部独立卡片，不展示 Excel库存/当前有效库存对比。
- 未来如需解释 Excel库存与当前有效库存差异，另行设计轻量差异提示；本卡不实施。
