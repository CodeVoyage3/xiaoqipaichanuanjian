## Gitee metadata

只接受恰好三个区分大小写的字符串字段：

```json
{
  "version": "x.x.x",
  "releaseNotes": "...",
  "manualDownloadUrl": "https://..."
}
```

- 最大 `256 KiB`；拒绝缺字段、额外字段、重复字段、错误类型与 malformed JSON。
- `version` 必须是无前缀、无前导零的严格三段数字版本。
- `manualDownloadUrl` 必须是绝对 HTTPS URI，默认 HTTPS 端口，无 user-info，host 当前只允许 `pan.quark.cn`。
- 未经真实官方链接取证，不得加入其他 `quark.cn` 子域或允许任意 HTTPS host。
- 更新说明沿用现有控制字符清理与完整滚动展示。
