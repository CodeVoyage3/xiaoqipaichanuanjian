## 唯一目标

在现有“数据导入”流程中，于本次成功导入后立即显示客观差异摘要；不新增导航、不做历史差异回看、不做经营建议、不改变导入、库存、任务或生命周期语义。

## 冻结业务口径

- 库存变化采用方案 A：本次 `ExcelStockQty` 对比导入前 Product 当前保存的 `ExcelStockQty`。
- “库存变为 0”仅统计已有商品且 before `> 0`、after `= 0`；新商品库存为 0 不计入。
- 新增商品只认现有 Product identity：规范化 `ProductCode` 在数据库中不存在；名称或条码变化不构成新增商品。
- 新增批次只认现有 Batch identity：有生产日期为 `ProductId + ProductionDate + ExpiryDate`；无生产日期为 `ProductId + ExpiryDate`。
- “本次未出现”以导入前最近一次 `Succeeded && !IsUndone` 的有效导入为基准；主数字按缺失批次数，允许辅助显示涉及商品数。
- “未出现但仍有未完成任务”是上述缺失批次中关联 `ProductTask.Status == "open"` 的只读子集；不得创建、修改、关闭或重开 Task/TaskItem。
- 首次有效导入没有历史基准：库存增加、库存减少、库存变 0、本次未出现、未出现仍有待办均显示 `—`，不显示 0。
- 导入异常以成功事务提交后按本次 ImportId 读取到的实际 `ImportIssue` 数量为最终口径。
- 本卡只交付本次成功导入后的即时摘要；软件关闭后不要求重开历史差异。

## 展示内容

第一层继续显示“导入成功”，至少包含本次商品数、批次数和实际异常数。

第二层标题“本次数据变化”，显示：

1. 新增商品
2. 新增批次
3. 库存增加
4. 库存减少
5. 库存变为 0
6. 本次未出现
7. 未出现但仍有未完成任务

继续复用现有异常列表；完全重复行可保留为预览信息，但不得造成 ImportIssue 最终计数重复。所有数字表示事实，不输出补货、订货、配货、折扣或风险建议。
