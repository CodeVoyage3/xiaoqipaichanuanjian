## 唯一目标

同一 installer/StoreExpiryInspector.iss 支持显式 SAME_SCHEMA_SLIM 与历史 CROSS_SCHEMA_FULL。v1.1.1 Slim 保留完整安装和 preflight payload，不嵌 ZIP、manifest、signature，并只允许真实已安装 EXE 版本不低于 1.1.0 的直接覆盖；fresh install 不受最低版本门禁影响。

## 实现

- .iss 强制二选一模式和 MinimumDirectVersion；仅 Full 要求、声明、提取并运行三项嵌入式更新资产。
- 已安装身份和真实 EXE 版本验证完成后，先执行最低直接版本门禁，再执行既有高版本降级阻断；低版本在任何 payload 复制前显示桥接升级提示并停止。
- 既有 installer preflight 保持：无数据库或当前完整 migration10 才允许 Slim；旧、未知/更高、损坏、unsafe WAL/data-root 仍 fail closed。
- Builder 从 Release Contract 的显式 setupCompatibility 取模式；schemaChanged 只做一致性验证。Slim 要求无 schema change 且禁止 cross-schema；Full 还要求已批准的 schema compatibility evidence。
- Builder 仍生成 ZIP、Setup、manifest、signature 四项资产；只有传给 ISCC 的嵌入参数随模式变化。
- receipt 为 schemaVersion 3，新增 setupMode、minimumDirectSetupVersion、embeddedUpdateAssets。
- release contract 只为历史 v1.1.0 记录真实 CROSS_SCHEMA_FULL / 1.0.9 / true；没有新增或伪造正式 v1.1.1 release 条目，v1.1.1 使用 test-only synthetic contract 验证。
