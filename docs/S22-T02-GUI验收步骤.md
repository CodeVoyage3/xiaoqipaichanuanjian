# S22-T02 用户真实 WPF GUI 验收

## 入口

双击同目录的 `S22-T02-开始验收.cmd`。

入口会自动：

1. 创建全新的 TEMP/GUID 隔离数据根。
2. 生成专用验收 Excel，并把完整路径复制到剪贴板。
3. 构建当前 S22-T02 Release 候选。
4. 打开本说明和隔离 WPF；不会读取或修改正式数据库。

## 操作步骤

1. 在 WPF 左侧进入“数据导入”。
2. 点击选择 Excel，在文件选择框地址/文件名位置按 `Ctrl+V` 粘贴入口已复制的路径并打开。
3. 预览完成后点击“确认导入”，等待出现“导入成功”。
4. 向下滚动检查“本次数据变化”。本 fixture 的固定预期为：
   - 新增商品：`1`
   - 新增批次：`1`
   - 库存增加：`1`
   - 库存减少：`1`
   - 库存变为 0：`1`
   - 本次未出现（批次）：`1`，涉及 `1` 个商品
   - 未出现仍有待办（批次）：`1`，涉及 `1` 个商品
5. 检查成功层显示实际数据异常数；下方列表标题必须是“导入前预览提示”，不得把预览行数冒充实际 ImportIssue 数。
6. 在 Windows 125% 缩放、窗口约 1024×600 下确认七项可读，页面可滚动；新增为蓝色/中性色，减少和变 0 为橙色，缺失待办为重点警示，异常为红色。
7. 关闭 WPF。隔离数据会保留在启动窗口显示的 TEMP/GUID 路径，正式数据不受影响。
